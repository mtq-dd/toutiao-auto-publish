# 今日头条发布助手

通过 CDP (Chrome DevTools Protocol) 控制 Edge 浏览器，全自动发布今日头条图文文章。

## 快速开始

```bash
# 1. 安装依赖
pip install -r tools/requirements.txt

# 2. 启动 Edge 调试模式
msedge --remote-debugging-port=9222

# 3. 在浏览器中登录 https://mp.toutiao.com

# 4. 运行发布
python tools/auto_publish_final.py \
    --title "文章标题" \
    --content path/to/content.html \
    --images path/to/images/
```

## 两种使用方式

### 方式 A：命令行直接运行

```bash
# 发布文章（含图片上传 + 自动发布）
python tools/auto_publish_final.py \
    --title "文章标题" \
    --content article.html \
    --images images/ \
    --cover-mode 三图

# 试运行（只填写内容，不发布）
python tools/auto_publish_final.py \
    --title "文章标题" \
    --content article.html \
    --images images/ \
    --dry-run

# 四项审查
python tools/full_review.py --title "标题" --content "正文" --images img1.jpg img2.jpg

# 检查候选话题与历史的相似度
python tools/hot_topic_manager.py check --candidates "话题A,话题B" --days 3

# 查看发布历史
python tools/hot_topic_manager.py history --days 7

# 生成当日发布报告
python tools/daily_report.py --date 20260613

# 页面诊断
python tools/toutiao_publisher.py diagnose
```

### 方式 B：Agent 通过 CLI 调用

Agent 接手项目时请阅读 `docs/AGENT_HANDOFF.md`，里面有完整的工具清单和调用流程。

## 图片上传方案

图片通过 **ClipboardEvent 粘贴**上传，已验证稳定工作：

1. 读取图片为 base64
2. 在页面中注入 JS，构造 `File` 对象 + `DataTransfer`
3. 向 `.ProseMirror` 编辑器派发 `ClipboardEvent('paste')`
4. 编辑器内置处理器自动上传图片到头条 CDN
5. 轮询等待图片出现在编辑器中（约 2-3 秒/张）

封面图片由编辑器自动从正文图片中选取，无需额外操作。

## 四项审查

- **文章质量**：字数、可读性、词汇多样性、标题评分
- **内容合规**：敏感词匹配、广告法违规、医疗/金融声明、引流检测
- **图片质量**：分辨率、模糊度（拉普拉斯方差）、亮度对比度
- **图片合规**：肤色比例检测（NSFW 初筛）、EXIF 隐私、色域异常

## 文章编写要求

- 标题 2-30 字
- 正文有一定深度，不能过于简单
- 配 3-4 张相关图片
- 图片和文字排版需要对应
- 不能违规，不能与历史文章重复

## 故障排除

**CDP 连接失败**：确认 Edge 已用 `--remote-debugging-port=9222` 启动，端口未被占用。

**找不到编辑器元素**：运行 `toutiao_diagnose_page` 查看页面状态，头条可能更新了前端结构。

**图片上传失败**：确认文件路径正确、格式为 JPG/PNG/WEBP，检查日志了解具体原因。
